Chrome manda a “dormir” el chat cuando lo cambiás por otra app y ahí no llegan avisos. Con este modo prendido, el chat hace un ruido ultra chiquito (no se escucha) y se queda despierto: los avisos siguen llegando. Gasta un poquito más de batería.

📱 ANDROID: 1) Tocá el candado 🔒 junto a la dirección → Notificaciones → Permitir. 2) Ajustes del cel → Aplicaciones → Chrome → Notificaciones → activadas. 3) El chat tiene que estar abierto (aunque esté en otra app). 4) Probá con otro dispositivo escribiéndote.

📱 IPHONE: primero instalá el chat como app: botón Compartir ⬆️ → “Agregar a pantalla de inicio” y entrá desde el ícono nuevo (iOS 16.4 o más nuevo). Sin instalarlo, iOS no deja que lleguen avisos.

Con el chat abierto y el Modo Siempre Activo prendido, llegan aunque estés en otra app. Y con el empuje 📲 activo (fila de arriba), los avisos llegan incluso con el chat totalmente cerrado 🧡

📲 ACTIVAR PUSH — AVISOS CON EL CHAT CERRADO

Los avisos que llegan aunque el chat esté totalmente cerrado (como WhatsApp) necesitan un servidorcito gratis. Se activa UNA sola vez en 3 pasos y queda listo para todos — después no hay que subir nada más.

1) Abrí dash.cloudflare.com (cuenta gratis).
2) Menú izquierdo → Workers & Pages → Create → Create Worker → nombre (ej: sikodark-push) → Deploy → Edit code.
3) Borrá TODO lo que trae y pegá el código copiado (mantener apretado → Pegar).
4) Botón Deploy (arriba a la derecha).
5) Copiá la URL que te dio: https://sikodark-push.tu-cuenta.workers.dev

—servidor de push

⚠️ Si ya habías creado el servidor antes, igual pegale este código nuevo (tiene mejoras) y dale Deploy de nuevo — la URL no cambia.

📱 iPhone: además de esto, el chat tiene que estar instalado como app (Compartir ⬆️ → Agregar a inicio). En Android anda con Chrome, instalado o no.
